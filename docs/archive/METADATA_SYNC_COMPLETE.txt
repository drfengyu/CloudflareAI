## ✅ 修复的问题（3 个）

### 问题 1: 模型未自动分类 ✅

**现象**:
- Vercel AI Gateway 提供 293 个模型（language/embedding/image/speech 等 8 种类型）
- 同步后全部分类为 "remote"，无法在 Playground 中按类别筛选

**修复**:
- 从上游 `type` 字段自动映射到本地 `category`
- language → text
- embedding → embeddings
- image → image
- speech/transcription → speech
- video → video
- reranking → classify

### 问题 2: 文本生成未显示上下文窗口 ✅

**现象**:
- Vercel 模型下拉框中显示 "ctx: —"（未知）

**修复**:
- 上游返回 `context_window` 字段（如 128000 = 128K）
- 同步时保留到 NormalizedModel
- Playground 显示真实值

### 问题 3: 定价固定为 100，未参考上游定价 ✅

**现象**:
- 所有模型 `multiplier = 1.0`，但 `inputPrice` / `outputPrice` 为 0
- 计费默认 100 credits（硬编码）

**修复**:
- 上游返回 `pricing: { input, output }` (USD/token)
- 转换公式：`credits per M tokens = USD/token × 1,000,000 × creditsPerUsd`
- 写入 `model_pricing` 表

## 🔧 技术实现

### 1. 扩展 UpstreamModel 接口

**文件**: `lib/channels/adapter.ts`

```typescript
export interface UpstreamModel {
  id: string;
  object: string;
  name?: string;                  // 友好名称
  description?: string;            // 模型描述
  type?: string;                   // 类型（language/embedding/image...）
  owned_by?: string;               // 厂商（alibaba/openai）
  context_window?: number;         // 上下文窗口 token 数
  max_tokens?: number;             // 单次输出上限
  tags?: string[];                 // 能力标签（reasoning/tool-use）
  pricing?: {
    input?: string;                // 输入定价 USD/token
    output?: string;               // 输出定价 USD/token
  };
}
```

### 3. 自动分类逻辑

**文件**: `lib/cloudflare/channel-catalog.ts`

```typescript
let category = "text";  // 默认
if (m.type === "language") category = "text";
else if (m.type === "embedding") category = "embeddings";
else if (m.type === "image") category = "image";
else if (m.type === "speech" || m.type === "transcription") category = "speech";
else if (m.type === "video") category = "video";
else if (m.type === "reranking") category = "classify";
```

### 4. 定价转换

**文件**: `app/api/channels/[channelId]/models/route.ts`

```typescript
const creditsPerUsd = await getCreditsPerUsd();  // 默认 1

if (model.upstreamPricing) {
  // USD/token × 1,000,000 × creditsPerUsd = credits per M tokens
  inputPrice = model.upstreamPricing.input * 1_000_000 * creditsPerUsd;
  outputPrice = model.upstreamPricing.output * 1_000_000 * creditsPerUsd;
}

await db.insert(modelPricing).values({
  modelId: model.id,
  category: model.category,           // ✅ 自动分类
  inputPrice: Math.round(inputPrice), // ✅ 真实定价
  outputPrice: Math.round(outputPrice),
  channelId,
  multiplier: 1.0,
  unit: "M tokens",
  isImage: model.category === "image" ? 1 : 0,
});
```

```typescript
      id: modelMeta.id,
      name: modelMeta.name,
```

## 📊 定价示例（Vercel AI Gateway）

| 模型 | 输入 (USD/token) | 输出 (USD/token) | 输入 (cr/M) | 输出 (cr/M) |
|------|-----------------|-----------------|------------|------------|
| Qwen3-14B | $0.00000012 | $0.00000024 | 0.12 | 0.24 |
| Qwen3-235B | $0.00000022 | $0.00000088 | 0.22 | 0.88 |
| Llama-3.3-70B | $0.00000018 | $0.00000018 | 0.18 | 0.18 |
| GPT-4o | $0.0000025 | $0.00001 | 2.5 | 10 |
| Claude-3.7-Sonnet | $0.000003 | $0.000015 | 3 | 15 |

**计算示例** (Qwen3-14B):
- 上游输入价: $0.00000012 / token
- credits per M tokens = 0.00000012 × 1,000,000 × 1 = **0.12 cr/M**
- 上游输出价: $0.00000024 / token
- credits per M tokens = 0.00000024 × 1,000,000 × 1 = **0.24 cr/M**

**对比旧版**:
- 旧版: inputPrice = 0, outputPrice = 0 → 默认扣 100 cr（硬编码）
- 新版: inputPrice = 0.12 cr/M, outputPrice = 0.24 cr/M → 按真实消耗扣费

```
    id: "alibaba/qwen-3-14b",
    type: "language",
    context_window: 40960,
    pricing: { input: "0.00000012", output: "0.00000024" }
  }
  ↓
适配器 (listModels)
  ↓
  UpstreamModel 对象（完整元数据）
  ↓
fetchChannelModels()
  ↓
  NormalizedModel {
    category: "text",
    contextWindow: 40960,
    upstreamPricing: { input: 0.00000012, output: 0.00000024 }
  }
  ↓
同步 API (POST /api/channels/[id]/models)
  ↓
  model_pricing 表 {
    modelId: "alibaba/qwen-3-14b",
    category: "text",
    inputPrice: 0.12,  // credits per M tokens
    outputPrice: 0.24,
    unit: "M tokens",
    channelId: "..."
  }
  ↓
Playground / 计费引擎
  ↓
  按真实定价扣费
```
