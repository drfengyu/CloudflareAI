# 限时活动·三国讨逆传（v0.53.0）

以《三国演义》为线索的长线剧情 RPG：从涿郡起兵，每处地方出城后是一张**类吞食天地的俯视行军
大地图**，四向自由走位、走到哪座营跟前就打哪座；拔尽此地营寨才出现下一处地名。战斗是回合制
兵团战（兵力、计策、阵型、招降），城里整备、编成、买卖装备。没有每日次数、没有限时——只有剧情推进。

- 前台：`/trial`（侧边栏入口「每日试炼」，页面标题「三国讨逆传」，活动中心默认展示）
- 后台：系统设置 → 「限时活动（每日试炼）」
- 配置键：`option.trial_config`（界面按字段拆成数字输入框，管理员不写 JSON）
- 引擎：`lib/trial/saga/`（存档归一、剧情数据、战斗 / 指令重放、行军结算）
  - `map.ts`：大地图生成（纯函数，按 `章节 + 营寨数 + 种子` 复现，不入库、不被采信）
- 渲染：`components/trial/renderer.ts`（俯视大地图与回合战斗两套 Canvas 像素场景，
  按 960×540 逻辑坐标绘制；画布位图再按显示尺寸 × devicePixelRatio 放大，上限 2×，
  每帧 `setTransform` 复位，所以桌面 1440 px 版心与手机端都不会糊）
- 客户端：`components/trial/game.tsx`（行走与碰撞、城与营的交互、编成商店、回合战斗、行军续局）
- 账本：`topup.type = 17`（平定奖励与钱庄存金在收兵结算时合并成一条正流水；
  钱庄换金在购买时写一条负流水；票价在券兑换 / 礼包时已按 type=15 记过支出，出城不再写负流水）
- 表：`trial_run`（迁移 `migrations/028_new_activity_games.sql`，沿用旧列：
  `questions` 存行军 JSON、`questionCount` = 营寨数、`correct` = 已攻破营寨数）

## 剧情推进

内部把八处地方编号为 `chapter = 0..7`，但界面上只出现地名与剧情：

| 序 | 城镇 | 剧情 | 首领 | 平定后入队 |
| --- | --- | --- | --- | --- |
| 0 | 涿郡 | 桃园起兵 · 讨伐黄巾 | 张角 | — |
| 1 | 陈留 | 汜水关 · 讨伐董卓 | 董卓 | — |
| 2 | 小沛 | 徐州风云 · 讨伐袁术 | 袁术 | 赵云 |
| 3 | 下邳 | 白门楼 · 讨伐吕布 | 吕布 | 张辽 |
| 4 | 延津 | 官渡之战 · 河北争锋 | 袁绍 | 诸葛亮 |
| 5 | 江夏 | 赤壁之战 · 孙刘联军 | 曹操 | 黄忠 |
| 6 | 涪城 | 入蜀之路 · 西川归心 | 刘璋 | 马超 |
| 7 | 五丈原 | 五丈原 · 秋风斜谷 | 司马懿 | 魏延 |

- 只有**拔尽当前地方的全部营寨**（收兵时 `victory`）才会把存档推进到下一处；
  中途兵败不推进，可回城住店重整后接着走，也可以收兵重新出城。
- 没走到的地方在界面上只显示「？？？ / 未至」，剧情文本在进入该地时展示。
- 平定最后一处后 `campaignComplete` 为真，服务端拒绝再开新行军，界面显示「全剧终」。
- 存档（武将等级 / 装备 / 金币 / 已平定地方 / 图鉴）随最近一行的 `endSave` 延续，
  下次行军从该存档继续；已平定地方仍可重走练级，但**不再发平定奖励**。

## 一次行军

1. 点「从{城镇}出发」，按票价折成**整数张**扣当期试炼活动券（`payWithCoupon`；
   `runPriceCredits` 被 `snapCostToUnit` 吸到券价整数倍，不足 1 张按 1 张）。
2. 服务端按种子生成这一路的营寨：默认 5 座（`questionCount`，上限 7）——
   普通战、精英、末座主帅本阵；地名取自当前地方的 `stages`。
   **地图不入库**：客户端与（隐含的）服务端都用 `generateSagaField({ 章节, 营寨数, 种子 })`
   画同一张图，落库的只有营寨列表与种子。
3. 出城即行军大地图（`scene = "field"`，52×34 格、每格 32 px）：
   - 方向键 / WASD 或触屏摇杆四向行走，也可点击地图上的城池 / 营寨自动走过去；
     镜头跟随，树林里减速（0.72 倍速），山 / 水 / 城墙挡路（脚底碰撞盒四角检测）。
   - 左下角小地图按地貌着色，标出城池、各营与主角位置。
   - 走到城门口按 E / 回车（或点「交互」）进城开面板：编成、阵型、铁匠铺 / 药铺、
     客栈、军需帐、钱庄、军情·收兵都在同一个「城中整备」面板里办。
   - 走到敌营跟前开营地面板：查看敌将与战利品，选择「出战」或「自动战斗」切入回合制战斗。
   - **攻打顺序由走位决定**：先打哪座营完全自由，只有主帅本阵要先拔尽其余营寨才肯出战
     （`canEngageNode`），其余营未清时打本阵的指令会被服务端丢弃且不会补打。
4. 城里 / 军需帐的花销与编制变化都记成指令：军需帐用**活动券**买局内增益
   （秘药 / 兵符 / 虎符 / 风行符 / 战鼓 / 锦囊），只在这次行军有效，被动军需每次限一份，
   购买从下一步行动起生效；钱庄可在金币与 tcr 之间双向兑换，客栈可花金币补满兵力（见下节）。
5. 战斗是五将回合制：
   - 每将每回合选 攻击 / 计策 / 防御 / 道具；计策有火计、回复、混乱、鼓舞，消耗计策点。
   - 阵型（鱼鳞 / 鹤翼 / 锋矢 / 方圆 / 长蛇）互相克制，改变攻防速。
   - 敌将兵力降到 35% 以下可招降；史实可降武将（含吕布、张辽等）通过概率检定入队，
     队伍满时进后备。
   - 战斗胜利得金币与经验，升级提升四维与兵力上限；全灭则兵败、全队兵力归零，
     行军退回「败退」状态：不能直接再出兵，要花 30 金住店重整（或收兵结束这趟）。
6. 收兵时服务端用种子重放全部指令，写回剧情存档并按**攻破的营寨数**命中档位发 tcr；
   只有平定当前地方才发，且全剧终后不再发。

## 钱庄与客栈（v0.53.0）

### 钱庄：可配置的双向兑换

规则写在 `lib/trial/saga/bank.ts`，汇率与单趟上限来自后台 `option.trial_config`，
**出城时冻结进本次行军**（`SagaRun.bank`），后台改价不影响在途存档；旧局没有
`bank` 字段时退回 `DEFAULT_SAGA_BANK`。

| 方向 | 比例 | 限制 | 到账时机 |
| --- | --- | --- | --- |
| 金币 → tcr | `bankGoldPerTcr`（默认 100 金 = 1 tcr） | 每次行军最多存 `bankMaxGoldPerRun`（默认 600 金） | 收兵结算时，与平定奖励合并成一条正流水 |
| tcr → 金币 | `bankGoldPerTcrBuy`（默认 1 tcr = 40 金） | 单笔 1~10000 tcr，且与存金共用单趟 600 金上限 | 购买即时到账：按购买记录在重放到该指令时加金 |

- **数量自选**：钱庄面板是两个数字输入框（存金按 `goldPerTcr` 取整档）+「全部」，
  实时显示本趟还能存 / 换多少金币。
- **换金价必须低于存金价**：后台保存时直接校验 `bankGoldPerTcrBuy < bankGoldPerTcr`，
  否则「100 金存成 1 tcr、再把 1 tcr 换回 100 金」可以无限刷金。默认 100 / 40 的
  价差意味着来回倒一次净亏 60%。
- **为什么不是 1 金 = 10 tcr**：一趟 5 座营全清给 `255 + 110×地方序` 金币，
  1:10 就是 2550 ~ 10250 tcr；而一次出城只要 1 张券（5 cr）。半途收兵刷金也能换
  数千 tcr——等于无限印钞。默认存金收益 ≤ 6 tcr/趟，仍低于刷金套利线。
- 实现：
  - 存金：重放指令 `{ k: "bank", g }`（重放时扣金、累计 `bankedGold`，
    服务端结算时按 `bankCreditsForGold(gold, run.bank)` 发 tcr）。
  - 换金：`buyTrialGold` 服务端校验额度与单趟上限后，用
    `spendCredits(..., { temporaryOnly: true })` 只扣未过期的临时 tcr，写一条
    `TOPUP_TYPE_TRIAL` 负流水，并把 `{ itemId: "bank_gold", gold, cmdIndex }`
    追加进 `purchases`（同一 `purchaseId` 幂等）。收兵重放时从该 `cmdIndex` 起
    把金币加进存档。CAS 冲突原路退 tcr 并删掉负流水。
  - 旧版 `gold_50 / 100 / 200` 档位购买记录读回时保留金币，不会因版本升级丢账。

### 客栈：花金币补兵力

价格写死在引擎里：`SAGA_INN_PRICE_GOLD = 30`（`lib/trial/saga/inn.ts`）。
收兵重放不读后台配置，客户端与服务器必须同价，所以不做成可配置项。

- 重放指令 `{ k: "inn" }` → `restAtInn`：全队任一上阵武将缺兵才收一次钱，
  把上阵武将补满；全队满编或金币不足 30 时返回 false、不扣钱。
- **兵败后也能住店**（v0.53.1）：`scene = "lost"` 时重放仍接受 `inn`，
  按 `restAtInn(state, revive)` 收钱补满，并把场景切回 `field`、清掉战败的 `battle`，
  后续出兵 / 购物 / 钱庄指令重新生效；店钱不足则仍困在败退状态，只能收兵。
  败退期间的战斗指令一律丢弃，避免零兵力白送。已破营寨不会回退。
- 兵力只存在于这次行军（`state.partyTroops`），收兵后不带走；下次出城重新满编。
  所以客栈是「残兵撑到下一处 / 兵败后重整」的补给点，不是永久成长。
- 界面在「城中整备 → 客栈」页签：逐将显示当前 / 最大兵力与血条；
  住店按钮对场景做区分提示——满编显示「兵力已满」、金币不足显示「金币不足」、
  兵败后显示「全军败退 · 住店重整（30 金）」并在金币不足时提示只能收兵。
  敌营面板与军情面板的败退框里也有「回城住店」按钮，直接走到客栈。

## 音乐与音效（v0.53.0）

- 全部由 `lib/game/audio.ts` 用 Web Audio 现场合成，不打包音频素材：行军场景
  `trial-field`（92 BPM 五声音阶）、交战 `trial-battle`（144 BPM 小调）。
- 默认关闭。HUD 右侧的 `SoundToggle` 点击后弹 `window.confirm` 二次确认才播放；
  选择记在 `localStorage`（`cloudai:game-audio`），刷新与换活动都沿用；
  离开活动页组件卸载时停掉曲目。
- 战斗音效 `playBattleSfx(events, 460)` 与服务端战斗事件的动画节拍对齐：
  攻击 → `hit`、计策 / 鼓舞 → `cast`、回复 → `heal`、防御 → `guard`、
  倒下 → `down`、招降 → `capture`、未命中 / 混乱 → `miss`、升级 → `coin`；
  进入战斗与结算另有 `encounter` / `win` / `lose`。

## 反作弊与幂等

- **只收指令**：出城、购买、编成都记为命令数组，交卷时服务端从 `startSave` + 种子
  从零重放；客户端的金币、等级、战果一概不采信。指令经 `sanitizeSagaCommands` 清洗，
  未知字段、错槽装备、未上阵武将的动作全部丢弃。
- **走位不入事实**：大地图的形状、营寨坐标、主角位置都是客户端按种子现算的，既不落库也不上传，
  所以「绕到营后」「走捷径」无法作弊。服务端只校验指令里的 `battle.node`
  （`canEngageNode`：下标合法、这座营还没破、主帅本阵必须先拔尽其余营寨），
  非法指令整条丢弃，之后也不会被补打——因此客户端必须自己拦下非法出战。
  走哪条路不影响任何数值，能改变结果的只有「打哪座营」和「这一仗怎么打」。
- **局内购买**：服务端单独扣券并写入 `purchases`（带 `cmdIndex`），重放时从该步起生效，
  不会回溯加强已经开打的战斗；同一 `purchaseId` 幂等，CAS 失败自动退款。
- **券余额即时可见**：页内的活动券兑换与礼包付完就 `router.refresh()`，
  `components/trial/game.tsx` 在渲染期把 `initialTickets` 对齐进本地 state
  （与 `lottery-wheel.tsx` 同一写法），出城弹窗不会因为本地旧余额一直卡在「券不足」；
  tcr 除了服务端结算入账，钱庄换金还会扣临时余额：换金成功后用服务端返回的
  `tcrBalance` 更新页内余额（`initialTcr` 仍作为渲染期对齐的初值）。
- **只发一次**：收兵用 `UPDATE trial_run ... WHERE status = 'active'` 抢占；断网重试命中
  `already`，返回首次结果，不重复发奖。发奖失败把状态改回 `active` 让用户能重交。
- **旧局兼容**：答题 / 浮游城 / 横版动作（JSON 版本不是 6）的 `active` 局在开局时
  就地换成新行军，不重复扣券。
- 活动结束后仍可收兵：只要这行属于当前轮次（`activityKey` 为开始时间），按开局时的配置结算。

## 奖励与配置

默认 `questionCount = 5`、`runPriceCredits = 5`、券单价 `5 cr`，档位 2/3/4/5 座营 →
1/2/4/8 tcr，奖励 `rewardValidDays = 30` 天内有效。只有平定当前地方且未全剧终时发放。

后台可改每处地方营寨数（2~7）、出城军令价、券单价、有效期与档位；
`tiers` 按营寨数升序去重，超出营寨数的档位由 `sanitizeTrialConfig` 丢弃。
钱庄三项：`bankGoldPerTcr`（2~1,000,000，默认 100）、`bankMaxGoldPerRun`
（按存金价向下取整到整档，默认 600）、`bankGoldPerTcrBuy`（默认 40，保存时强制
小于存金价）。
