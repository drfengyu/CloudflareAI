# 限时活动·每日试炼：浮游城（v0.44.0）

一座最多 7 层的浮游城：每层先在两扇野区门里选路，再挑战层主，击败层主才能上楼。
地图与随机种子在开局时落库，浏览器只上交「选门 / 剑技 / 道具」的动作序列，
服务端用同一套纯函数重算层数与剩余血量——改前端存档拿不到更多奖励。

- 前台：`/trial`（侧边栏「每日试炼」，活动中心默认展示）
- 后台：系统设置 → 「限时活动（每日试炼）」
- 配置键：`option.trial_config`（界面按字段拆成数字输入框，管理员不写 JSON）
- 引擎：`lib/trial/dungeon.ts`（生成、解析、确定性重放，服务端与客户端共用）
- 账本：`topup.type = 17`（奖励只发 tcr；票价在券兑换 / 礼包时已按 type=15 记过支出，开局不再写负流水）
- 表：`trial_run`（迁移 `migrations/028_new_activity_games.sql`，沿用旧列：
  `questions` 存地图 JSON、`questionCount` = 总层数、`correct` = 通关层数）

## 玩法

1. 点「LINK START」，按票价折成**整数张**扣当期试炼活动券（`payWithCoupon`；
   `runPriceCredits` 被 `snapCostToUnit` 吸到券价整数倍，不足 1 张按 1 张）。
2. 服务端生成浮游城（版本 4）：每层两扇野区门 + 一间层主房，门从
   战斗 / 精英 / 宝箱 / 营地 里抽，至少保证一扇是战斗或精英；层主按层数成长，
   默认 5 层，`questionCount` 上限 7。
3. 每层只能走一扇野区门；也可以不探路直接进层主房。选门后进入逐回合战斗：
   - 剑技：线性攻击（无冷却）、水平弧斩（2 回合冷却）、切换防守（格挡 14 并回 4 血）、
     星屑飞溅（4 回合冷却、高伤）。
   - 连击：连续进攻每次 +2 伤害、最多 +10；防守或挨打清零。
   - 道具：回复结晶每局 2 个，使用一次回 32 血。
   - 层主生命低于 40% 进入狂暴，伤害 ×1.35。
4. 宝箱立刻给装备；精英怪击破后才给装备。装备（锐刃、翠绿护腕、迅捷之靴、生命结晶、
   吸魂戒指、破甲短剑、烈焰附魔、向导之灯）可叠层，跨房间生效。
5. 击破怪物回 6 血并获得经验（战斗 `14+3×层`、精英 `28+5×层`、层主 `45+8×层`），
   升级时生命上限 +10 并回 10 血；营地回 28 血。生命跨房间保留，死亡即结束。
6. 击败层主上楼，通关全部层数即登顶。按**通关层数**命中最高一档发 tcr。
7. 中途关页面不丢局：动作序列存在浏览器 `localStorage`（`trial-dungeon:{runId}`），
   回来接着打；未交卷的那局 `status = active`，不会重复扣券。
8. 每日最多 `dailyRuns` 局，按北京时间自然日统计（`countTrialRunsToday`）。

## 反作弊与幂等

- **只收动作**：交卷只上传 `enter / boss / skill / item` 序列，服务端用种子重放；
  非法动作兜底为第一扇门 / 线性攻击，死亡或通关后的动作忽略。
- **超时**：用时超过「限时 + 5 秒宽限」记 `expired`，按 0 层处理，不返还券。
- **瞬交**：用时短于「每层 1.5 秒、下限 8 秒且不超过限时」的下限，通关层数清零。
- **只发一次**：交卷用 `UPDATE trial_run ... WHERE status = 'active'` 抢占；断网重试命中
  `already`，返回首次结果，不重复发奖。发奖失败把状态改回 `active` 让用户能重交。
- **旧局兼容**：答题 / 单排波次 / 旧版地下城的 `active` 局（JSON 版本不是 4）在开局时就地
  换成新地图，不重复扣券。
- 活动结束后仍可交卷：只要这局属于当前轮次（`activityKey` 为开始时间），按开局时的配置结算。

## 奖励与配置

默认 `questionCount = 5`、`timeLimitSeconds = 300`、`dailyRuns = 3`、`runPriceCredits = 5`、
券单价 `5 cr`，档位 2/3/4/5 层 → 1/2/4/8 tcr，奖励 `rewardValidDays = 30` 天内有效。

后台可改层数（≤ 7）、限时（≥ 15 秒）、每日局数、票价、券单价、有效期与档位；
`tiers` 按通关层数升序去重，超出层数的档位由 `sanitizeTrialConfig` 丢弃。
