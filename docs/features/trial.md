# 限时活动·三国讨逆传（v0.57.1）

以《三国演义》为线索的长线剧情 RPG：从涿郡起兵，每处地方出城后是一张**类吞食天地的俯视行军
大地图**，四向自由走位、走到哪座营跟前就打哪座；拔尽此地营寨才出现下一处地名。战斗是回合制
兵团战（兵力、计策、阵型、招降），城里整备、编成、买卖装备。没有每日次数、没有限时——只有剧情推进。

- 前台：`/trial`（侧边栏入口「每日试炼」，页面标题「三国讨逆传」，活动中心默认展示）
- 后台：系统设置 → 「限时活动（每日试炼）」
- 配置键：`option.trial_config`（界面按字段拆成数字输入框，管理员不写 JSON）
- 引擎：`lib/trial/saga/`（存档归一、剧情数据、战斗 / 指令重放、行军结算）
  - `map.ts`：大地图生成（纯函数，按 `章节 + 营寨数 + 种子` 复现，不入库、不被采信）
  - `encounter.ts`：野外遭遇编成（按 `种子 + 第几场` 推出兵士 / 山贼 / 盗贼与可选敌将）
  - `training.ts`：训练场逐级训练（上限随平定数增长，券价按级差计）
  - `story.ts`：剧情场景（开场 / 阵前 / 平定 / 乡野 / 酒馆 / 议事）与城池 NPC 台词
  - `quests.ts`：军令（任务），进度从重放状态与乡野走访现算，不单独存档
- 渲染：`components/trial/renderer.ts`（俯视大地图与回合战斗两套 Canvas 像素场景，
  按 960×540 逻辑坐标绘制；战斗队列纵向排列，顶部两军各占半屏血条面板，底部留给战报与
  指令浮层；画布位图再按显示尺寸 × devicePixelRatio 放大，上限 2×，
  每帧 `setTransform` 复位，所以桌面 1440 px 版心与手机端都不会糊）；
  `components/trial/portraits.ts` 程序化武将立绘（按装备换装）
- 客户端：`components/trial/game.tsx`（行走与碰撞、城与营的交互、街景与店铺面板、
  剧情对话浮层、编成商店、回合战斗、行军续局）；`components/trial/scenes.tsx`
  承载街景 / 营地 / 对话浮层 / 军令与立绘组件
- 账本：`topup.type = 17`（平定奖励与钱庄存金在自动结算时合并成一条正流水）；
  城内买卖（装备 / 药品 / 军需 / 客栈 / 训练）在购买时按券扣费，写 `payWithCoupon` 的 type=15 支出；
  **出城免费**，不按票价扣券
- 表：`trial_run`（迁移 `migrations/028_new_activity_games.sql`，沿用旧列：
  `questions` 存行军 JSON、`questionCount` = 营寨数、`correct` = 已攻破营寨数）

## 剧情、军令与场景（v0.56.0）

- **剧情对话**：`lib/trial/saga/story.ts` 按地方生成 `SagaScene`——
  `chapterIntroScene` 开场旁白、`campScene` 阵前喊话（按敌将给台词）、
  `chapterVictoryScene` 平定收尾、`poiScene` 乡野见闻、`tavernScene` 酒馆旧事、
  `councilScene` 营帐议事（按当前上阵武将点名）。台词只由地方与行军状态现算，不入库；
  同一场景在本地记住已看过（`trial-saga-town:*` 的 `scenes`），刷新后不重复弹。
- **军令**：`quests.ts` 从 `SagaReplayState` 推出 2 条主线（拔除外营 / 直取中军）
  与 6 条支线（招降 1 将、胜 3 场、全员披挂、走访三处乡野、存金 100、练到 10 级）。
  只有「走访乡野」来自本地见闻，其余全部来自服务端重放结果；`sagaNextQuest` 主线优先，
  军令只是引导，不参与任何结算。
- **城中街景**：进城后画布换成街景（`TownScene` + `paintTownBackdrop`），
  桃园碑 / 编成所 / 酒馆 / 铁匠铺 / 药铺 / 军需帐 / 客栈 / 钱庄 / 营帐 / 城门
  都是可点的铺面；点进去才打开对应面板，面板顶部有 NPC 立绘与迎宾词（`NpcIntro`）。
  新增「营帐」页签（召集众将议事 + 军令 + 队伍立绘）与酒馆「听一段旧事」。
  城池只是界面，买卖仍走原有券价与购买记录。
- **立绘与换装**：`components/trial/portraits.ts` 用 FNV 哈希从武将 ID 生成脸型 /
  须发 / 甲胄纹样，武器与护甲分四档改变甲色、盔饰与兵器剪影；编成所、队伍列表、
  图鉴、战斗双方与对话浮层都读当前装备，换装立刻反映在立绘上。

## 武将特性与成长（v0.57.0）

- **固有特性**：`lib/trial/saga/data.ts` 的 `SAGA_TRAITS` 给武将挂「无双 / 智圣 / 会心 / 猛将 /
  铁壁 / 神速 / 仁德」，效果写进四维与战斗参数：
  - 无双（吕布）：武力 +6、普攻 +10%、两成概率追击一次；
  - 智圣（诸葛亮 / 庞统 / 法正 / 曹操 / 司马懿等）：智力 +8、开局计策点 +1、计策效果 +20%；
  - 会心（赵云 / 黄忠 / 马超）：暴击率 +22%、暴击伤害 ×1.7；
  - 猛将（关羽 / 张飞 / 魏延等）：武力 +6、普攻 +12%；
  - 铁壁（严颜 / 董卓 / 曹仁 / 高顺等）：防御 +8、受伤 -12%；
  - 神速（张任 / 太史慈 / 甘宁 / 张郃等）：速度 +8、一成概率追击一次；
  - 仁德（刘备）：开局计策点 +1、计策效果 +15%。
  特性只在战斗规则 `rules >= 2` 的行军生效；敌方武将的特性同样参与伤害计算。
- **追击与暴击**：会心 / 无双 / 神速的追击走战斗 RNG，结果写进战报（「暴击」「追击」）；
  特性不会跨行军累积，也不写入存档。
- **策略点随等级增长**：`rules >= 2` 时每名武将开局计策点 = `2 + 智力/30 + (等级-1)/3 +
  军需加成 + 特性加成`，封顶 12 点（旧规则仍是原来的 `2 + 智力/30`，封顶 9）。
- **计策领悟**：`tacticsFor(def, level)` 把基础计策与 `learn` 里已到等级的计策合并；
  智将在 8 / 10 / 12 / 14 / 16 级等节点学会新计策，战斗指令栏会立刻出现。
- **规则版本**：`SAGA_RULESET = 2` 写进行军 JSON 的 `rules`；v0.56 及更早的行军缺省按
  `rules = 1` 重放，不启用特性、成长计策与升级策略点，旧存档战果不变。

## 自动存档、撤退与训练场（v0.57.0）

- **自动存档**：客户端每产生一条指令（出战、结束战斗、购物、换阵、存金等），
  700 ms 防抖后把整段 `commands` 回传 `autoSaveTrialAction`；服务端 `saveTrialRunProgress`
  用整段行军 JSON 做乐观锁重放校验后写库。HUD 显示「存档中… / 已自动存档」。
  刷新页面时 `initialCommands` 取「本机 localStorage 指令」与「服务端指令」中更长的一份，
  本机进度领先（自动存档尚未追上）也不会被旧存档覆盖。
- **自动结算**：服务端在自动存档重放中发现 `scene === "won"`（此地营寨尽拔）时直接调用
  内部结算，返回 `settled` 与 `settlement`；客户端不再有「收兵」按钮，收到结果后清掉本机缓存、
  弹出结算卡。未平定就关页面不会结算，回来接着走。
- **撤退不是结束行军**：战斗中的「撤退」先追加本场已打的战斗块，再追加 `{ k: "retreat" }`；
  重放时 `retreatFromBattle` 把当前兵力写回队伍，还有人站着就回到 `field` 继续走，
  全军倒下才进入 `lost`。已攻克营寨、金币、经验、招降、装备全部保留，之前指令也不会丢。
- **训练场**：城中新增「训练场」铺面（NPC 周教头）。选武将、填目标等级，按
  `trainingCost(当前, 目标) = 级差 × 2 张券` 实时扣券，购买记录带 `generalId` / `targetLevel`；
  重放时 `trainGeneral` 把等级抬到目标值，`exp` 归零。上限 `trainingLevelCap` =
  `9 + 已平定地方数 × 3`，最高 30 级；超过上限的目标按上限处理，已在目标等级以上不收费。
- **军中一览**：行军大地图上点空白处（不撞营 / 乡野 / 城池）打开「军中一览」面板，
  逐将显示等级、四维、兵力条、经验、特性与已学计策，并列出上阵 / 后备、行囊道具、
  装备库存与队伍编制；战斗中点敌将立绘可直接设为目标。

## 一次行军

1. 点「从{城镇}出发」**免费**出城，不再扣试炼券；活动券留到城里买卖时按商品券价扣。
2. 服务端按种子生成这一路的营寨：默认 5 座（`questionCount`，上限 7）——
   普通战、精英、末座主帅本阵；地名取自当前地方的 `stages`。
   **地图不入库**：客户端与（隐含的）服务端都用 `generateSagaField({ 章节, 营寨数, 种子 })`
   画同一张图，落库的只有营寨列表与种子。
3. 出城即行军大地图（`scene = "field"`，76×48 格、每格 32 px）：
   - 方向键 / WASD 或触屏摇杆四向行走；点城池 / 敌营 / 乡野地标会自动走过去。
     镜头跟随，树林里减速（0.72 倍速），山 / 水 / 城墙挡路（脚底碰撞盒四角检测）。
   - 左下角小地图按地貌着色，标出城池、各营、乡野点位与主角位置。
   - 每张图在官道上铺了村落 / 祠堂 / 渡口三处地标（`SagaFieldPoi`），走到跟前按 E
     看一段乡野见闻；走访只记在本机，用于支线军令。
   - 走到城门口按 E / 回车（或点「交互」）进城，画布换成可点的街景：
     编成、阵型、铁匠铺 / 药铺、客栈、军需帐、钱庄、酒馆、营帐、训练场、活动券与
     桃园碑分别进铺子办理。
   - 点空白处打开「军中一览」，随时查武将、道具、装备与队伍；走位不会因此中断。
   - 走到敌营跟前开营地面板：敌将立绘与阵前喊话 + 战利品，选择「出战」或「自动战斗」切入回合制战斗。
   - 草地 / 树林会随机遇敌（见下节「野外遇敌」），官道与城内外安全；遭遇战不占营地进度。
   - **攻打顺序由走位决定**：先打哪座营完全自由，只有主帅本阵要先拔尽其余营寨才肯出战
     （`canEngageNode`），其余营未清时打本阵的指令会被服务端丢弃且不会补打。
4. **城内买卖一律用活动券**（试炼券）：铁匠铺的武器护甲、药铺的伤药 / 良药 / 金疮药 / 大还丹、
   军需帐的局内增益（秘药 / 兵符 / 虎符 / 风行符 / 战鼓 / 锦囊）、客栈住店与训练场逐级训练
   都按商品券价在购买时实时扣券，购买记录带 `cmdIndex`，从下一步行动起生效；军需只在这次行军有效，
   被动军需每次限一份。城中还有**活动券礼包**入口（兑换 / 购买后余额即时刷新）。
   **金币不再能直接买东西**：战斗缴获的金币只能在钱庄存成 tcr，平定此地自动结算时与
   通关奖励一起到账（见下节）。
5. 战斗是五将回合制：
   - 每将每回合在战斗画面下方选 攻击 / 计策 / 防御 / 道具 / 招降；计策有火计、回复、混乱、鼓舞，
     消耗计策点，主将身负「无双 / 智圣 / 会心 / 猛将」等固有特性。
   - 阵型（鱼鳞 / 鹤翼 / 锋矢 / 方圆 / 长蛇）互相克制，改变攻防速。
   - 敌将兵力降到 35% 以下可招降；史实可降武将（含吕布、张辽等）通过概率检定入队，
     队伍满时进后备。
   - 战斗胜利得金币与经验，升级提升四维与兵力上限；计策点随等级增长，智将在特定等级领悟新计策。
   - 全灭则兵败、全队兵力归零，行军退回「败退」状态：不能直接再出兵，要花 1 张试炼券住店重整；
     撤退只结束当前这一场，回到大地图接着走。进度每一步都会自动存档。
6. 拔尽当前地方的全部营寨后，服务端在自动存档重放中判定 `victory`，**自动结算**并写回剧情存档，
   按**攻破的营寨数**命中档位发 tcr；只有平定当前地方才发，且全剧终后不再发。
   不再有手动「收兵」按钮，未平定就离开会保留进度。

## 野外遇敌（v0.54.0）

`lib/trial/saga/encounter.ts` + `components/trial/game.tsx` 的逐格判定。

- **触发**：行走时每跨入一个新格子判定一次（`fieldEncounterChanceAt`）：
  官道 / 城墙 / 城内外 / 海边滩涂 0，草地 2.4%，树林 5%。战后冷却 18 格、出城冷却 12 格，
  边按键边走、点击寻路都会触发；触发即停下当前寻路，开遭遇战面板。
- **编成**：`sagaEncounterFor(run, ordinal)` 只读 `run.seed` 与「本趟第几场」：
  兵种三选一（兵士守高、山贼攻高、盗贼速高），1~3 队杂兵，38% 概率由当前地方的
  敌将领头（合计最多 4 队）；等级、兵力、金币与经验随当前地方与场次成长。
  野外敌军全部不可招降，胜利照常计入等级、金币、经验与图鉴。
- **上限**：每趟最多 `SAGA_MAX_ENCOUNTERS = 10` 场；达到上限后不再判定，
  防止站在草地里原地刷金。战报记录 `encounters` 并在结算卡显示「野外遭遇 N 场」。
- **重放**：结束后上传 `{ k: "skirmish", rounds }`；服务端只在 `scene === "field"`
  且场次未满时受理，按同一序号重建敌军并逐回合重放。打赢回到 `field`（不占营地、
  不推进章节），打输进入 `lost`，与营寨战一样花 1 张试炼券住店重整。
- **界面**：HUD 显示「遭遇 n/10」；遭遇战标题显示「敌军 N 队」。撤退会把本场已打的回合
  一起存档，只结束这一场遭遇，回到大地图继续行军；进度不会因此丢失。
- **安全地形（v0.57.1）**：官道、城墙与城内外原本就不判定；现在挨着水面的草地算**海边滩涂**，
  同样不遇敌，渲染器会在水边画一圈沙岸与浪线，走上去一眼可辨。营地 / 乡野点位扫出的空地
  只铺草地、保留已修好的官道，官道不再被空地截断——沿着路走不会再突然遇敌。

## 存档排序与空壳行军（v0.57.1）

- **`startedAt` 混排**：早期收尾分支用 `d1Run` 直接绑 `Date`，D1 HTTP 驱动会把参数
  JSON 化成 ISO 文本写进 INTEGER 列；SQLite 排序时 TEXT 恒大于 INTEGER，
  `ORDER BY startedAt DESC` 会把一条旧的兵败记录当成最新，于是平定后回到城镇一刷新，
  存档就被旧的 `endSave` 顶掉——等级、装备与购买全「回档」。
  `lib/trial/store.ts` 的 `startedAtDesc` 用
  `CASE WHEN typeof(startedAt) = 'text' THEN CAST(strftime('%s', startedAt) AS INTEGER) * 1000
  ELSE startedAt END` 统一按真实毫秒排序，读存档、找进行中行军、查历史记录共用；
  新的收尾分支也改为直接绑毫秒数。
- **空壳行军**：出城后没有落下任何 `commands`、没有 `purchases`、`shopSeq` 仍为 0 的行军
  （刷新 / 误关页面留下的）由 `sagaRunUntouched` 判定为没有进度，
  `findActiveTrialRun` 不把它当作进行中的行军；下一次「出发」走 `startTrialRun` 的旧行替换分支，
  按修正后的最新存档重开，不会把玩家卡在上一处地方。真正打过的行军（哪怕只有一次撤退）照旧续局。

## 经济：券流通、金币只存不换（v0.55.0）

v0.55 起取消出城券费与金币商店：**活动券（试炼券）是城内唯一流通货币**，
金币只作为战斗缴获，在钱庄单向往 tcr 折算。

### 城内商店：全部按券计价

- 价目表在 `lib/trial/saga/data.ts`：武器 1/2/3/5 张、护甲 1/2/3/5 张、伤药 1 张、
  良药 2 张；军需 1~2 张。`SagaItemDef.priceTickets` 是唯一价格字段，
  服务端 `buyTrialItem` 按它乘券面单价 `couponUnitCredits` 扣券。
- 购买记录只存 `{ itemId, tickets, cmdIndex }`，重放时券价以商品表为准，
  客户端写回的张数不采信；被动军需每次限一份，客栈与消耗品可重复购买。
- 旧版金币商店指令 `{ k: "shop" }`、`{ k: "inn" }` 已从指令类型和
  `sanitizeSagaCommands` 中移除，改版后的客户端伪造也会被丢弃；
  历史行军里已落库的 `bank_gold` / `gold_*` 购买记录仍按旧价读回，不会丢账。

### 钱庄：金币 → tcr 单向

规则写在 `lib/trial/saga/bank.ts`，汇率与单趟上限来自后台 `option.trial_config`，
**出城时冻结进本次行军**（`SagaRun.bank`），后台改价不影响在途存档；旧局没有
`bank` 字段时退回 `DEFAULT_SAGA_BANK`。

| 方向 | 比例 | 限制 | 到账时机 |
| --- | --- | --- | --- |
| 金币 → tcr | `bankGoldPerTcr`（默认 100 金 = 1 tcr） | 每次行军最多存 `bankMaxGoldPerRun`（默认 600 金） | 平定此地自动结算时，与平定奖励合并成一条正流水 |

- **数量自选**：钱庄面板一个数字输入框（按 `goldPerTcr` 取整档）+「全部」，
  实时显示本趟还能存多少金币。
- **不再开放 tcr → 金币**：钱庄面板只剩存金一栏；`SagaBankPolicy.goldPerTcrBuy`
  只用于读回历史 `bank_gold` 记录，不再出现在后台表单与页面上。
- **为什么不是 1 金 = 10 tcr**：一趟 5 座营全清给 `255 + 110×地方序` 金币，
  1:10 就是 2550 ~ 10250 tcr。默认存金收益 ≤ 6 tcr/趟，与平定奖励同一量级。
- 实现：重放指令 `{ k: "bank", g }`（重放时扣金、累计 `bankedGold`，
  服务端结算时按 `bankCreditsForGold(gold, run.bank)` 发 tcr）。

### 客栈：1 张券住一次

价格写死在引擎里：`SAGA_INN_PRICE_TICKETS = 1`（`lib/trial/saga/inn.ts`）。
结算重放不读后台配置，客户端与服务器必须同价，所以不做成可配置项。

- 住店走购买记录 `{ itemId: "inn_rest" }`：购买时 `buyTrialItem` 扣 1 张券，
  重放 `applyPurchase` 调 `restAtInn` 把上阵武将兵力补满。
- **兵败后也能住店**：`scene = "lost"` 时住店记录会把场景切回 `field`、清掉战败的
  `battle`，后续出兵 / 购物 / 钱庄指令重新生效；没有住店记录则仍困在败退状态。
  败退期间的战斗指令一律丢弃，避免零兵力白送。已破营寨不会回退。
- 兵力只存在于这次行军（`state.partyTroops`），结算后不带走；下次出城重新满编。
  所以客栈是「残兵撑到下一处 / 兵败后重整」的补给点，不是永久成长。
- 界面在「城中整备 → 客栈」页签：逐将显示当前 / 最大兵力与血条；
  住店按钮对场景做区分提示——满编显示「兵力已满」、券不足显示「试炼券不足」、
  兵败后显示「全军败退 · 住店重整（1 张券）」并提示住店后可直接再战。
  敌营面板与军情面板的败退框里也有「回城住店」按钮，直接走到客栈。

## 音乐与音效（v0.53.0）

- 全部由 `lib/game/audio.ts` 用 Web Audio 现场合成，不打包音频素材：行军场景
  `trial-field`（92 BPM 五声音阶）、交战 `trial-battle`（144 BPM 小调）。
- 默认关闭。HUD 右侧的 `SoundToggle` 点击后弹 `window.confirm` 二次确认才播放；
  选择记在 `localStorage`（`cloudai:game-audio`），刷新与换活动都沿用；
  离开活动页组件卸载时停掉曲目。
- 战斗音效 `playBattleSfx(events, 460)` 与服务端战斗事件的动画节拍对齐：
  攻击 → `hit`、计策 / 鼓舞 → `cast`、回复 → `heal`、防御 → `guard`、
  倒下 → `down`、招降 → `capture`、未命中 / 混乱 → `miss`、升级 → `coin`；
  进入战斗与结算另有 `encounter` / `win` / `lose`。

## 反作弊与幂等

- **只收指令**：出城、购买、编成、战斗、撤退都记为命令数组，服务端从 `startSave` + 种子
  从零重放；客户端的金币、等级、战果一概不采信。指令经 `sanitizeSagaCommands` 清洗，
  未知字段、错槽装备、未上阵武将的动作全部丢弃；`{ k: "retreat" }` 只在战斗场景生效。
- **自动存档**：`saveTrialRunProgress` 把整段 `commands` 与数据库里的行军 JSON 做乐观锁
  （`WHERE questions = ?`），每次都先重放校验再写回；客户端每 700 ms 防抖回传一次，
  刷新时优先采用本机与服务端中更长的一份指令，所以断电 / 关页面最多丢最后一步。
- **自动结算**：自动存档重放到 `scene === "won"` 时直接调用与手动交卷相同的
  `submitTrialRun`，靠 `UPDATE trial_run ... WHERE status = 'active'` 抢占，
  返回的 `settled` / `settlement` 让客户端清缓存并弹结算卡；没有「收兵」入口。
- **走位不入事实**：大地图的形状、营寨坐标、主角位置都是客户端按种子现算的，既不落库也不上传，
  所以「绕到营后」「走捷径」无法作弊。服务端只校验指令里的 `battle.node`
  （`canEngageNode`：下标合法、这座营还没破、主帅本阵必须先拔尽其余营寨）与
  `skirmish`（仅行军途中、每趟 ≤ 10 场）；非法指令整条丢弃，之后也不会被补打——
  因此客户端必须自己拦下非法出战。走哪条路、什么时候撞上敌人不影响任何数值，
  敌军编成由种子与场次推出；能改变结果的只有「打哪座营、打不打这场遭遇」和「这一仗怎么打」。
- **局内购买**：服务端单独扣券并写入 `purchases`（带 `cmdIndex`），重放时从该步起生效，
  不会回溯加强已经开打的战斗；同一 `purchaseId` 幂等，CAS 失败自动退款。
- **券余额即时可见**：页内的活动券兑换与礼包付完就 `router.refresh()`；
  城内每次购买成功后用服务端返回的 `tickets` 更新本地余额，
  `components/trial/game.tsx` 在渲染期把 `initialTickets` 对齐进本地 state
  （与 `lottery-wheel.tsx` 同一写法），买完 / 刷新后按钮不会卡在旧余额。
- **只发一次**：自动结算 / 手动结算都用 `UPDATE trial_run ... WHERE status = 'active'` 抢占；
  断网重试命中 `already`，返回首次结果，不重复发奖。发奖失败把状态改回 `active` 让用户能重交。
- **旧局兼容**：答题 / 浮游城 / 横版动作（JSON 版本不是 6）的 `active` 局在开局时
  就地换成新行军；v0.56 及更早的讨逆传行军 `rules = 1`，按旧战斗规则重放；出城已免费，
  不存在补扣或退券。
- 活动结束后仍可自动结算：只要这行属于当前轮次（`activityKey` 为开始时间），按开局时的配置结算。

## 奖励与配置

默认 `questionCount = 5`、券单价 `5 cr`，档位 2/3/4/5 座营 → 1/2/4/8 tcr，
奖励 `rewardValidDays = 30` 天内有效。只有平定当前地方且未全剧终时发放。

后台可改每处地方营寨数（2~7）、券单价、有效期与档位；`tiers` 按营寨数升序去重，
超出营寨数的档位由 `sanitizeTrialConfig` 丢弃。钱庄两项：`bankGoldPerTcr`
（2~1,000,000，默认 100）、`bankMaxGoldPerRun`（按存金价向下取整到整档，默认 600）。
