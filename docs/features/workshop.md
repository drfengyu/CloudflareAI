# 限时活动·灵宠工坊（v0.45.0）

红白机式养成：开局三选一初始灵宠，花活动券在区域里探索、遭遇野生灵宠，用招式打倒或
精灵球捕捉，升级到门槛自动进化，按徽章顺序挑战三个道馆，图鉴记录见过的每一阶。
两只同阶灵宠仍可合成一只高一阶，作为不花券的加速路径。

- 前台：`/workshop`（侧边栏「灵宠工坊」，活动中心默认展示）
- 后台：系统设置 → 「限时活动（灵宠工坊）」
- 配置键：`option.workshop_config`（界面按字段拆成数字输入框，管理员不写 JSON）
- 账本：`topup.type = 18`（里程碑只发 tcr；探索 / 道馆票价在券兑换 / 礼包时已按 type=15 记过支出）
- 表：`workshop_state`（沿用迁移 `migrations/028_new_activity_games.sql`，无新增迁移）
- 里程碑幂等：`activity_milestone` 唯一索引 `(userId, activityKind, activityKey, tierKey)`

## 玩法

1. **三选一**：第一次进入从焰尾狐（ember）/ 潮汐鲸（tide）/ 森语鹿（verdant）里选一只
   Lv.5 初始灵宠，不花券；选定后不可更换（`starter` 固定）。
2. **探索**：花一次 `exploreCostCredits` 的当期工坊券在某片区域抽一只野生灵宠，等级 / 阶数
   由区域区间决定；区域按徽章数解锁（灰烬原野 → 潮声浅滩 → 苔语密林 → 星陨高地）。
3. **战斗**：每只灵宠两个招式（普通系「撞击」+ 本系技），属性三角
   焰 → 森 → 潮 → 焰（克制 ×1.5、被克 ×0.67）。可选防御（本回合受伤减半）、换人、
   喝药水、扔精灵球、逃跑；道馆战不能捕捉或逃跑。
4. **捕捉**：精灵球只对野生灵宠有效，成功率随残血上升、随阶数下降，夹在 5%~92%。
5. **成长**：战斗胜利给经验，升级补足生命上限差值；到达该阶进化等级（6 / 10 / 14 … / 34）
   自动升阶并回满新增血量，第 9 阶是终点，50 级封顶。
6. **队伍与仓库**：队伍 3 只、仓库 60 只；战斗中可换人，倒地自动换下一只活着灵宠，
   全灭判负并结束遭遇。药水回复 20 点，每天可免费休息一次回满整队。
7. **道馆**：按徽章数顺序挑战三座道馆，胜利发徽章 + 2 精灵球 + 2 药水；三枚徽章解锁星陨高地。
8. **合成**（保留）：两只同线同阶灵宠合成一只高一阶（取两者较高等级、满血），不花券、
   不会失败；队伍↔队伍留在队伍，仓库内合成留在仓库。
9. **里程碑**：任意一条线首次达到配置阶位发一次 tcr，`tierKey = tier:N`；判定取图鉴与当前
   灵宠的最高阶，合成消耗掉低阶灵宠也不会让已达成阶位回退。
10. **图鉴**：3 条线 × 9 阶，拥有某阶即视为见过 1~该阶；未解锁格位显示剪影。

## 存档结构

整份进度存 `workshop_state.state` JSON：`day / exploresToday / gymsToday / starter / party /
box / dex / items{ball,potion} / badges / activePetId / encounter / restDay`。纯数据与纯函数
在 `lib/workshop/state.ts`、`lib/workshop/pets.ts`，服务端与单测共用。

旧版「三条线各阶数量」存档（`items: { ember: number[], ... }`）在 `normalizeWorkshopState`
时换算成灵宠个体：等级按 `阶数 × 4`，按阶数排序后前 3 只进队伍、其余进仓库（合计上限 63），
同一天的采集次数保留为探索次数，图鉴按灵宠阶数补齐，老玩家不用从 1 级重练。

## 服务端结算

- 客户端只提交「这一回合做什么」（`move / guard / ball / potion / switch / run`），伤害、捕捉、
  掉落、经验全部由 `resolveWorkshopBattle` 在服务端计算，随机数可注入，单测固定序列。
- 探索与道馆先扣券再写状态：CAS 连续 3 次失败、每日次数用完或创建遭遇失败时，
  `refundCouponPayment` 把券退回原处。
- 写入用 `WHERE version = ?` 乐观锁；并发战斗 / 捕捉只有一个能推进，另一个收到「操作冲突，请刷新后重试」。
- 里程碑先 `INSERT OR IGNORE` 占住 `activity_milestone` 唯一键再发 tcr；发奖失败删掉占位行。

## 配置

默认每日探索 20 次、单次 2 cr；每日道馆 3 次、单次 5 cr；券单价 2 cr；休息免费；里程碑
3/5/7/9 阶 → 6/15/30/80 tcr，奖励 `rewardValidDays` 天内有效。后台可改次数、票价、券单价、
有效期与任意阶位里程碑；票价按券单价对齐整张，阶位越界 / 重复由 `sanitizeWorkshopMilestones` 丢弃。
旧配置字段 `dailyGathers` / `gatherCostCredits` 读回时作为 `dailyExplores` / `exploreCostCredits`
的兜底，升级不会重置管理员调过的次数与票价。
