## 复现方式

- 贴图 / 音频 / 脚本 / MonoBehaviour 字符串：`UnityPy`
- 音频压缩：`imageio-ffmpeg` → OGG q4
- 装备表：MonoBehaviour 尾部 4 字节字段为「类型 + 数值」，`2=攻`、`3=防`、`5=智`、`6=速`
- 商店表：`resources.assets` 里 `*-武器店` / `*-道具店` 对象的 12 字节条目，前 4 字节是文件号，后 4 字节是对象 pathId

原始桌面版路径不要写进代码，本目录就是稳定副本。
